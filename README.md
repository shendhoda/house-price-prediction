# House Price Prediction - Machine Learning

An end-to-end machine learning project that predicts
residential house prices based on property features
such as location, size, bedrooms, and construction quality.

## Project Overview

This project uses historical King County, Washington,
housing transactions from 2014-2015.

It demonstrates the complete ML workflow:

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature engineering and categorical encoding
- Machine learning model training
- Model comparison and evaluation
- Interactive predictions with Streamlit
- REST API development with FastAPI

## Technologies

- Python
- pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- FastAPI
- Joblib

## Machine Learning Models

The following algorithms are compared:

1. Dummy Regressor (Median Baseline)
2. Ridge Regression
3. Random Forest Regressor

The best model is selected using validation MAE
and evaluated on a separate test set.

## Dataset

King County House Sales Dataset

Source:
https://www.kaggle.com/datasets/harlfoxem/housesalesprediction

The dataset contains 21,613 historical house sales.

The original CSV is not included in this repository.

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/house-price-prediction.git
cd house-price-prediction
```

Create a virtual environment:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Download the dataset from Kaggle and save it as:

`data/kc_house_data.csv`

## Usage

Run exploratory analysis:

```bash
python explore.py
```

Train the machine learning models:

```bash
python train.py
```

Make a prediction:

```bash
python predict.py
```

Launch the Streamlit app:

```bash
streamlit run app.py
```

Launch the FastAPI server:

```bash
uvicorn api:app --reload
```

Interactive API documentation:

http://127.0.0.1:8000/docs

## Model Evaluation

The models are evaluated using:

- MAE: Mean Absolute Error
- RMSE: Root Mean Squared Error
- R²: Coefficient of Determination

Evaluation results are generated by `train.py`
and saved in `models/metrics.json`.

## Limitations

The model is trained on historical housing data
from 2014-2015 and is intended for educational use.

Predictions should not be interpreted as current
property valuations or financial advice.
